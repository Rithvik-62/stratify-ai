# STRATIFY UiPath Automation

This folder contains the automation files for the STRATIFY project.

## Main file
- `STRATIFY_REPORT_AUTOMATION.xaml` — UiPath workflow file for demonstration and showcase

## Python implementation used by the workflow
- `uipath_automation.py` — actual automation logic that detects PDF reports, archives older files, and sends email

## How to use it
1. Open UiPath Studio.
2. Create a new project or open this file as a workflow file.
3. Ensure the Python path is valid on your machine.
4. Run the workflow.

## Notes
This is designed for demonstration and project showcase. The actual execution logic is in the Python file, which is already configured for the current STRATIFY project.
